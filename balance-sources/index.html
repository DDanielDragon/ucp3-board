On “last update”: JSON balances (GitHub / in the UCP install) carry a real commit date, so freshness is checkable automatically. Google Sheets don't expose a last-edited date without the Google Drive API (login required) — you have to open the sheet and check File → Version history. This is a strong argument for using the JSON sources (also downloadable straight from UCP3, per Nevikov: ucp/plugins/<balance>/resources/balance/*.json) as the canonical, auto-checkable source.
